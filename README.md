# NetMagen Vision — installer downloads

This repository only hosts the Windows installer for **NetMagen Vision**
(the NetMagen camera recorder / NVR). The application's source code is private.

- Download the latest installer from the **Releases** page on the right.
- Product page and system requirements: https://netmagen.com/en/vision/app/download
- Each release attaches `checksums.txt` (SHA-256) next to the installer.

Requirements: Windows 10/11 64-bit. The installer is per-user (no administrator
rights needed). It is not code-signed yet, so Windows SmartScreen shows
"Windows protected your PC" — click **More info → Run anyway**.
